# 🌊 Sistema SADAE

> Sistema de Água e Esgoto - Projeto de Faturamento e Gestão de Serviços

Este repositório contém o Sistema SADAE completo, uma aplicação web moderna para gerenciamento de serviços de água e esgoto.

## 📂 Estrutura do Repositório

```
Sistema Sadae/
├── README.md                    # Este arquivo
├── .gitignore                   # Arquivos ignorados pelo Git
├── package.json                 # Dependências do projeto principal
└── rpiv_project04/             # Aplicação principal
    ├── README.md               # Documentação detalhada
    ├── frontend/               # Aplicação React modernizada
    ├── services/               # Serviços backend
    └── shared/                 # Código compartilhado
```

## 🚀 Status do Projeto

### ✅ Concluído
- **Frontend Modernizado**: Interface responsiva com React + TypeScript + Tailwind CSS
- **Componentes Reutilizáveis**: Biblioteca completa de componentes UI
- **Sistema de Faturamento**: Visualização, filtros avançados e modais funcionais
- **Dados Mock**: Dataset completo para demonstração
- **Design Responsivo**: Interface adaptativa para todos os dispositivos

### 🔄 Em Desenvolvimento
- **Backend API**: Serviços Python com FastAPI
- **Banco de Dados**: Integração com PostgreSQL
- **Autenticação**: Sistema JWT
- **Integração Frontend-Backend**: Substituição dos dados mock

## 🎯 Funcionalidades Principais

- 💰 **Faturamento Inteligente**: Gestão completa de faturas com filtros avançados
- 📋 **Sistema de Contestações**: Processo estruturado para contestar faturas
- 🤝 **Negociações**: Propostas de parcelamento e acordos de pagamento
- 📊 **Dashboard Analítico**: Visão geral com estatísticas em tempo real
- 🔍 **Busca Avançada**: Filtros por status, período, valor e ordenação
- 📱 **Interface Responsiva**: Experiência otimizada para todos os dispositivos

## 💻 Tecnologias

### Frontend
- React 18.2.0 + TypeScript
- Tailwind CSS 3.2.0
- TanStack React Query
- Vite (Build Tool)

### Backend (em desenvolvimento)
- Python + FastAPI
- SQLAlchemy ORM
- PostgreSQL
- JWT Authentication

## 🚀 Como Executar

```bash
cd rpiv_project04/frontend
```
