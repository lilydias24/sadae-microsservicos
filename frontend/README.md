Sistema Auxiliar de Departamento de Água e Esgoto — SADAE

O que foi implementado até agora

- **Tela de Login:** Autenticação simulada para acesso ao sistema.
- **Dashboard:** Exibe estatísticas principais, gráficos de nível de água e pressão, e alertas recentes. Todos os dados são mocados para fins de apresentação visual.
- **Tela de Monitoramento:** Visualização em tempo real (simulada) dos sensores da rede, incluindo:
  - Lista de sensores ativos, status (normal, alerta, crítico), valores e localizações.
  - Gráfico em tempo real de um sensor de pressão.
  - Listagem de anomalias detectadas, com severidade e data.
